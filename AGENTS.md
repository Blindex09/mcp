# Instruções para agentes

As instruções deste repositório ficam no `CLAUDE.md`, na raiz: as regras mestras (obrigatórias para tudo), o processo
de trabalho e o checklist antes de concluir qualquer mudança. O texto integral de cada regra está em `.claude/rules/`.
Leia o `CLAUDE.md` inteiro antes de começar.

foi trocado por este aviso em 19/10/2026 para que não existam duas versões que possam divergir, como já foi feito nos
projetos Agentic (02/10/2026) e Qaaccessibility (08/10/2026).
