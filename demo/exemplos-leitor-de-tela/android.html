Android (Jetpack Compose)

No Compose a acessibilidade vem da árvore de semântica. clickable, toggleable e ListItem já juntam os filhos num só item; ícones precisam de descrição; mudanças que o usuário não vê precisam de liveRegion; títulos de seção usam heading().

Exemplo ruim: Ícone clicável sem descrição

Não executado aqui: este MCP não tem Android. O código segue a documentação do Jetpack Compose (developer.android.com, semântica de acessibilidade, lida em 2026-10-19). Teste com o TalkBack num aparelho ou emulador.

Por quê

O TalkBack encontra um item clicável sem nome: diz só que é botão ou nada. Com contentDescription nulo, o ícone não tem texto nenhum. A área de toque também não é garantida.

O que corrigir

Use IconButton com contentDescription que diga a ação ("Curtir"). contentDescription = null só serve quando um texto ao lado já dá o nome.

Código

Icon(
    imageVector = Icons.Default.Favorite,
    contentDescription = null,
    modifier = Modifier.clickable { curtir() }
)

Exemplo bom: IconButton com descrição

Não executado aqui: este MCP não tem Android. O código segue a documentação do Jetpack Compose (developer.android.com, semântica de acessibilidade, lida em 2026-10-19). Teste com o TalkBack num aparelho ou emulador.

Por quê

O IconButton traz o papel de botão e a área de toque mínima; a descrição diz a ação.

O que corrigir

Nada a corrigir.

Código

IconButton(onClick = { curtir() }) {
    Icon(
        imageVector = Icons.Default.Favorite,
        contentDescription = "Curtir"
    )
}

Exemplo ruim: Mensagem de status que muda em silêncio

Não executado aqui: este MCP não tem Android. O código segue a documentação do Jetpack Compose (developer.android.com, semântica de acessibilidade, lida em 2026-10-19). Teste com o TalkBack num aparelho ou emulador.

Por quê

O texto muda na tela, mas nenhum serviço de acessibilidade é avisado: quem usa o TalkBack não ouve que salvou.

O que corrigir

Marque o texto de status como região viva.

Código

var status by remember { mutableStateOf("") }
Button(onClick = { status = "Salvo com sucesso" }) { Text("Salvar") }
Text(status)

Exemplo bom: Região viva educada

Não executado aqui: este MCP não tem Android. O código segue a documentação do Jetpack Compose (developer.android.com, semântica de acessibilidade, lida em 2026-10-19). Teste com o TalkBack num aparelho ou emulador.

Por quê

liveRegion = Polite faz o TalkBack anunciar a mudança sem interromper. Use Assertive só para o que não pode esperar, e nunca em texto que muda o tempo todo, como um cronômetro.

O que corrigir

Nada a corrigir.

Código

var status by remember { mutableStateOf("") }
Button(onClick = { status = "Salvo com sucesso" }) { Text("Salvar") }
Text(
    text = status,
    modifier = Modifier.semantics { liveRegion = LiveRegionMode.Polite }
)

Exemplo ruim: Título de seção que é só texto grande

Não executado aqui: este MCP não tem Android. O código segue a documentação do Jetpack Compose (developer.android.com, semântica de acessibilidade, lida em 2026-10-19). Teste com o TalkBack num aparelho ou emulador.

Por quê

Para quem vê é um título. Para o TalkBack é uma linha de texto: não dá para pular de seção em seção.

O que corrigir

Marque como título na semântica.

Código

Text("Pedidos recentes", style = MaterialTheme.typography.headlineSmall)

Exemplo bom: Título marcado com heading()

Não executado aqui: este MCP não tem Android. O código segue a documentação do Jetpack Compose (developer.android.com, semântica de acessibilidade, lida em 2026-10-19). Teste com o TalkBack num aparelho ou emulador.

Por quê

heading() deixa os serviços de acessibilidade navegarem direto entre os títulos.

O que corrigir

Nada a corrigir.

Código

Text(
    text = "Pedidos recentes",
    style = MaterialTheme.typography.headlineSmall,
    modifier = Modifier.semantics { heading() }
)
