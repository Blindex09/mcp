Árvore (tree view)

Uma árvore de pastas e arquivos precisa de role=tree, itens treeitem, aria-expanded nos pais e as setas: para baixo e para cima andam, para a direita abre, para a esquerda fecha. Uma lista aninhada comum não faz nada disso.

Nesta página

  1. Exemplo ruim: Listas aninhadas abertas só com clique
  2. Exemplo bom: Tree view no padrão do APG

Exemplo ruim: Listas aninhadas abertas só com clique

  • Documentos
    • contrato.pdf
    • nota.txt
  • leia-me.md

Por quê

Só o mouse abre a pasta. O leitor de tela ouve uma lista, a pasta não é um controle, não diz se está aberta e o teclado não alcança nada.

O que corrigir

Use role=tree, role=treeitem, aria-expanded nas pastas, tabindex rotativo e as setas (direita abre, esquerda fecha, Home e End).

O que o navegador entrega ao leitor de tela (medido)

- list:
  - listitem: Documentos
  - listitem: leia-me.md

O que o axe acha (medido)

O axe não achou nada neste exemplo. É um problema que só aparece olhando a árvore de acessibilidade ou ouvindo com o leitor de tela.

Comportamento com o teclado (sonda tree, medido)

NÃO cumpriu: o elemento fica dentro de um role=tree. Observado: nao ha role=tree ao redor.
NÃO cumpriu: os itens tem role=treeitem (pelo menos dois visiveis). Observado: 0 itens visiveis.

Código

Código copiado

<ul id="arv-ruim"><li><span class="pasta-ruim">Documentos</span><ul hidden><li>contrato.pdf</li><li>nota.txt</li></ul></li><li>leia-me.md</li></ul><script>Array.prototype.forEach.call(document.querySelectorAll('.pasta-ruim'),function(p){p.style.cursor='pointer';p.addEventListener('click',function(){var u=p.nextElementSibling;u.hidden=!u.hidden;});});</script>

Exemplo bom: Tree view no padrão do APG

  • Documentos
    • contrato.pdf
    • nota.txt
  • leia-me.md

Por quê

O leitor de tela anuncia árvore, item, nível e se está aberto ou fechado. As setas andam, abrem e fecham, e há uma única parada de Tab.

O que corrigir

Nada a corrigir.

O que o navegador entrega ao leitor de tela (medido)

- tree "Arquivos":
  - treeitem "Documentos"
  - treeitem "leia-me.md"

O que o axe acha (medido)

O axe não achou nenhuma violação (nível AA).

Comportamento com o teclado (sonda tree, medido)

cumpriu: o elemento fica dentro de um role=tree. Observado: sim.
cumpriu: os itens tem role=treeitem (pelo menos dois visiveis). Observado: 2 itens visiveis.
cumpriu: a arvore tem nome (aria-label ou aria-labelledby). Observado: 'Arquivos'.
cumpriu: a arvore (ou um item) recebe o foco do teclado. Observado: li 'Documentos'.
cumpriu: todo item que tem filhos expoe aria-expanded true/false. Observado: 1 de 1 pais com estado.
cumpriu: so uma parada de Tab na arvore (item atual com tabindex 0, ou a arvore com aria-activedescendant). Observado: 1 paradas de Tab.
cumpriu: Seta para baixo move o foco para o proximo item visivel. Observado: item atual 0 -> 1.
cumpriu: Home vai ao primeiro item e End ao ultimo visivel. Observado: Home->0, End->1 de 2 visiveis.
cumpriu: Seta para a direita abre um item fechado. Observado: aria-expanded false -> true.
cumpriu: Seta para a esquerda fecha um item aberto. Observado: aria-expanded true -> false.

Código

Código copiado

<style>#arv-bom [role=group]{display:none;list-style:none;padding-left:1.25rem}#arv-bom [aria-expanded=true]>[role=group]{display:block}#arv-bom,#arv-bom ul{list-style:none;padding-left:1rem}#arv-bom [role=treeitem]{padding:0.35rem 0.25rem}</style><ul id="arv-bom" role="tree" aria-label="Arquivos"><li role="treeitem" aria-expanded="false" tabindex="0" id="arv-bom-doc">Documentos<ul role="group"><li role="treeitem" tabindex="-1">contrato.pdf</li><li role="treeitem" tabindex="-1">nota.txt</li></ul></li><li role="treeitem" tabindex="-1">leia-me.md</li></ul><script>(function(){var t=document.getElementById('arv-bom');function vis(){return Array.prototype.slice.call(t.querySelectorAll('[role=treeitem]')).filter(function(e){var r=e.getBoundingClientRect();return r.width>0&&r.height>0;});}function ir(el){t.querySelectorAll('[role=treeitem]').forEach(function(e){e.tabIndex=-1;});el.tabIndex=0;el.focus();}t.addEventListener('keydown',function(e){var v=vis(),i=v.indexOf(document.activeElement),el=document.activeElement;e.stopPropagation();if(e.key==='ArrowDown'){e.preventDefault();ir(v[Math.min(i+1,v.length-1)]);}else if(e.key==='ArrowUp'){e.preventDefault();ir(v[Math.max(i-1,0)]);}else if(e.key==='Home'){e.preventDefault();ir(v[0]);}else if(e.key==='End'){e.preventDefault();ir(v[v.length-1]);}else if(e.key==='ArrowRight'&&el.getAttribute('aria-expanded')==='false'){e.preventDefault();el.setAttribute('aria-expanded','true');}else if(e.key==='ArrowRight'&&el.getAttribute('aria-expanded')==='true'){e.preventDefault();ir(v[i+1]);}else if(e.key==='ArrowLeft'&&el.getAttribute('aria-expanded')==='true'){e.preventDefault();el.setAttribute('aria-expanded','false');}});t.addEventListener('click',function(e){var it=e.target.closest('[role=treeitem]');if(it){ir(it);if(it.hasAttribute('aria-expanded')&&e.target===it)it.setAttribute('aria-expanded',String(it.getAttribute('aria-expanded')!=='true'));}});})();</script>
