Diálogo (janela modal)

Ao abrir um diálogo, o foco do teclado precisa entrar nele, ficar preso lá dentro, e voltar ao botão que o abriu quando ele fecha. O leitor de tela anuncia o nome do diálogo.

Nesta página

  1. Exemplo ruim: Caixa que aparece, mas o foco fica para trás
  2. Exemplo bom: dialog nativo com showModal()

Exemplo ruim: Caixa que aparece, mas o foco fica para trás

Excluir este projeto?

Por quê

Para quem vê, abriu uma janela. Para o teclado e o leitor de tela, não é um diálogo: a caixa não tem papel de diálogo nem nome, o foco continua no botão de trás, o Tab vaza para a página e o Escape não fecha. A sonda do MCP nem reconhece uma janela aberta.

O que corrigir

Use o elemento dialog aberto com showModal(): ele dá papel, foco preso, Escape e fundo inerte. Dê nome com aria-labelledby apontando para o título.

O que o navegador entrega ao leitor de tela (medido)

- button "Excluir projeto"

O que o axe acha (medido)

O axe não achou nada neste exemplo. É um problema que só aparece olhando a árvore de acessibilidade ou ouvindo com o leitor de tela.

Comportamento com o teclado (sonda dialog, medido)

cumpriu: o gatilho recebe o foco do teclado. Observado: button 'Excluir projeto'.
NÃO cumpriu: Enter no gatilho abre um dialogo visivel. Observado: nenhum dialogo (papel dialog/alertdialog ou <dialog open>) visivel depois do Enter.

Código

Código copiado

<button type="button" id="abrir-dlg-ruim">Excluir projeto</button><div id="dlg-ruim" class="caixa-falsa" hidden><p>Excluir este projeto?</p><button type="button" id="fechar-dlg-ruim">Cancelar</button></div><script>(function(){var d=document.getElementById('dlg-ruim');document.getElementById('abrir-dlg-ruim').addEventListener('click',function(){d.hidden=false;});document.getElementById('fechar-dlg-ruim').addEventListener('click',function(){d.hidden=true;});})();</script>

Exemplo bom: dialog nativo com showModal()

Excluir este projeto?

Isso não pode ser desfeito.

Por quê

O navegador coloca o foco dentro, prende o Tab, fecha com Escape, devolve o foco ao botão e anuncia o diálogo pelo nome do título.

O que corrigir

Nada a corrigir.

O que o navegador entrega ao leitor de tela (medido)

- button "Excluir projeto"

O que o axe acha (medido)

O axe não achou nenhuma violação (nível AA).

Comportamento com o teclado (sonda dialog, medido)

cumpriu: o gatilho recebe o foco do teclado. Observado: button 'Excluir projeto'.
cumpriu: Enter no gatilho abre um dialogo visivel. Observado: abriu <dialog> role=None.
cumpriu: o foco entra no dialogo ao abrir. Observado: dentro.
cumpriu: o dialogo tem nome (aria-label ou aria-labelledby). Observado: 'Excluir este projeto?'.
cumpriu: aria-modal=true ou <dialog> aberto com showModal(). Observado: aria-modal=None :modal=True.
cumpriu: Tab circula so entre os controles do dialogo (o foco nao vaza para a pagina). Observado: circulou dentro e voltou ao inicio em 3 Tab.
cumpriu: Escape fecha o dialogo. Observado: fechou.
cumpriu: ao fechar, o foco volta ao elemento que abriu o dialogo. Observado: button 'Excluir projeto'.

Código

Código copiado

<button type="button" id="abrir-dlg-bom">Excluir projeto</button><dialog id="dlg-bom" aria-labelledby="dlg-bom-titulo"><h3 id="dlg-bom-titulo">Excluir este projeto?</h3><p>Isso não pode ser desfeito.</p><button type="button" id="cancelar-dlg-bom">Cancelar</button> <button type="button">Excluir</button></dialog><script>(function(){var d=document.getElementById('dlg-bom');document.getElementById('abrir-dlg-bom').addEventListener('click',function(){d.showModal();});document.getElementById('cancelar-dlg-bom').addEventListener('click',function(){d.close();});})();</script>
