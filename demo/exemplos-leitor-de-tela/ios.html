iOS (SwiftUI e UIKit)

No iOS o VoiceOver lê o rótulo, o valor e os traços de cada elemento. Toque num texto ou imagem com onTapGesture não vira botão; imagens decorativas precisam sair da árvore; mudanças que o usuário não vê precisam ser anunciadas.

Exemplo ruim: Imagem com onTapGesture

Não executado aqui: este MCP não tem iOS. As APIs vieram de artigos de terceiros; a página oficial da Apple não pôde ser lida. Confirme em developer.apple.com e teste com o VoiceOver num aparelho.

Por quê

O VoiceOver lê o nome do símbolo ("heart") ou nada, sem dizer que é botão, e o toque pode ficar menor que o mínimo.

O que corrigir

Use Button e dê um rótulo que diga a ação.

Código

Código copiado

Image(systemName: "heart")
    .onTapGesture { curtir() }

Exemplo bom: Button com rótulo

Não executado aqui: este MCP não tem iOS. As APIs vieram de artigos de terceiros; a página oficial da Apple não pôde ser lida. Confirme em developer.apple.com e teste com o VoiceOver num aparelho.

Por quê

Button traz o traço de botão; accessibilityLabel diz a ação em vez do nome do símbolo.

O que corrigir

Nada a corrigir.

Código

Código copiado

Button(action: curtir) {
    Image(systemName: "heart")
}
.accessibilityLabel("Curtir")

Exemplo ruim: Título de seção que é só texto grande

Não executado aqui: este MCP não tem iOS. As APIs vieram de artigos de terceiros; a página oficial da Apple não pôde ser lida. Confirme em developer.apple.com e teste com o VoiceOver num aparelho.

Por quê

Para quem vê é um título. Para o VoiceOver é texto comum: o rotor de títulos não o encontra.

O que corrigir

Acrescente o traço de título.

Código

Código copiado

Text("Pedidos recentes")
    .font(.title2)

Exemplo bom: Título com o traço isHeader

Não executado aqui: este MCP não tem iOS. As APIs vieram de artigos de terceiros; a página oficial da Apple não pôde ser lida. Confirme em developer.apple.com e teste com o VoiceOver num aparelho.

Por quê

O traço isHeader põe o texto no rotor de títulos do VoiceOver.

O que corrigir

Nada a corrigir.

Código

Código copiado

Text("Pedidos recentes")
    .font(.title2)
    .accessibilityAddTraits(.isHeader)

Exemplo ruim: Mensagem de status que só aparece na tela

Não executado aqui: este MCP não tem iOS. As APIs vieram de artigos de terceiros; a página oficial da Apple não pôde ser lida. Confirme em developer.apple.com e teste com o VoiceOver num aparelho.

Por quê

O texto muda, mas o VoiceOver não é avisado: quem não vê a tela não sabe que salvou.

O que corrigir

Poste um anúncio de acessibilidade quando o estado mudar.

Código

Código copiado

@State private var status = ""
Button("Salvar") { status = "Salvo com sucesso" }
Text(status)

Exemplo bom: Anúncio de acessibilidade

Não executado aqui: este MCP não tem iOS. As APIs vieram de artigos de terceiros; a página oficial da Apple não pôde ser lida. Confirme em developer.apple.com e teste com o VoiceOver num aparelho.

Por quê

UIAccessibility.post com a notificação de anúncio faz o VoiceOver falar a mensagem. No iOS 17 também existe a forma de SwiftUI (AccessibilityNotification); confirme na documentação da Apple.

O que corrigir

Nada a corrigir.

Código

Código copiado

@State private var status = ""
Button("Salvar") {
    status = "Salvo com sucesso"
    UIAccessibility.post(notification: .announcement, argument: status)
}
Text(status)
