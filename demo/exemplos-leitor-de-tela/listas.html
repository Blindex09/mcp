Listas

O leitor de tela anuncia uma lista com a quantidade de itens e a posição de cada um. Lista só no visual não é anunciada.

Exemplo ruim: Lista falsa feita de divs com bolinha no texto

• Sencha
• Matcha
• Gyokuro

Por quê

Para quem vê é uma lista. Para o leitor de tela são três linhas soltas, sem "lista com 3 itens" e sem posição. A bolinha ainda pode ser lida como símbolo.

O que corrigir

Use ul e li. O marcador (bolinha) vem do CSS e não do texto.

O que o navegador entrega ao leitor de tela (medido)

- text: • Sencha • Matcha • Gyokuro

O que o axe acha (medido)

O axe não achou nada neste exemplo. É um problema que só aparece olhando a árvore de acessibilidade ou ouvindo com o leitor de tela.

Código

<div>• Sencha</div><div>• Matcha</div><div>• Gyokuro</div>

Exemplo bom: Lista de verdade

  • Sencha
  • Matcha
  • Gyokuro

Por quê

O navegador entrega uma lista com 3 itens. O leitor de tela anuncia o total e a posição de cada item.

O que corrigir

Nada a corrigir.

O que o navegador entrega ao leitor de tela (medido)

- list:
  - listitem: Sencha
  - listitem: Matcha
  - listitem: Gyokuro

O que o axe acha (medido)

O axe não achou nenhuma violação (nível AA).

Código

<ul><li>Sencha</li><li>Matcha</li><li>Gyokuro</li></ul>

Exemplo ruim: Lista de cartões com um título dentro de cada item

  • Sencha

    Chá verde japonês.

  • Matcha

    Chá verde em pó.

Por quê

É HTML válido, mas a mesma informação aparece duas vezes: o leitor de tela anuncia "lista com 2 itens" e, em cada item, um título com o nível do h3. Quem navega por títulos passa a encontrar rótulos de cartão no lugar da estrutura da página. O guia aria-rules-dos-and-donts do MCP diz para usar título na estrutura do documento e não em título visual de cartão, e para expor cada informação uma só vez.

O que corrigir

Troque por uma lista de links com descrição: ul, li e, dentro do item, o link com o nome do cartão e o parágrafo. A lista dá a contagem e os saltos; o link já é o nome. Se cada cartão for mesmo uma seção que merece estar no mapa da página, deixe os títulos e tire a lista, nunca os dois.

O que o navegador entrega ao leitor de tela (medido)

- list:
  - listitem:
    - heading "Sencha" [level=3]:
      - link "Sencha":
        - /url: "#sencha"
    - paragraph: Chá verde japonês.
  - listitem:
    - heading "Matcha" [level=3]:
      - link "Matcha":
        - /url: "#matcha"
    - paragraph: Chá verde em pó.

O que o axe acha (medido)

O axe não achou nada neste exemplo. É um problema que só aparece olhando a árvore de acessibilidade ou ouvindo com o leitor de tela.

Código

<ul class="cartoes"><li><h3><a href="#sencha">Sencha</a></h3><p>Chá verde japonês.</p></li><li><h3><a href="#matcha">Matcha</a></h3><p>Chá verde em pó.</p></li></ul>

Exemplo bom: Lista de cartões como lista de links com descrição

  • Sencha

    Chá verde japonês.

  • Matcha

    Chá verde em pó.

Por quê

Uma só estrutura: o leitor de tela anuncia a lista com o total de itens e, em cada item, o link com o nome do cartão e a descrição. A lista de títulos da página continua só com os títulos de verdade.

O que corrigir

Nada a corrigir.

O que o navegador entrega ao leitor de tela (medido)

- list:
  - listitem:
    - link "Sencha":
      - /url: "#sencha"
    - paragraph: Chá verde japonês.
  - listitem:
    - link "Matcha":
      - /url: "#matcha"
    - paragraph: Chá verde em pó.

O que o axe acha (medido)

O axe não achou nenhuma violação (nível AA).

Código

<ul class="cartoes"><li><a href="#sencha">Sencha</a><p>Chá verde japonês.</p></li><li><a href="#matcha">Matcha</a><p>Chá verde em pó.</p></li></ul>
