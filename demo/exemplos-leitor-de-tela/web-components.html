Web Components (elemento personalizado)

Um elemento personalizado com Shadow DOM aberto continua sendo medido pelo MCP. O defeito comum é o mesmo de sempre, só que escondido dentro do shadow: um div clicável. O bom entrega um botão de verdade, ou usa ElementInternals para dar o papel e o estado ao próprio elemento.

Nesta página

  1. Exemplo ruim: Elemento personalizado com div clicável no shadow
  2. Exemplo bom: Elemento personalizado com button no shadow
  3. Exemplo ruim: Caixa de seleção personalizada sem papel nem teclado
  4. Exemplo bom: Caixa de seleção personalizada com ElementInternals

Exemplo ruim: Elemento personalizado com div clicável no shadow

Por quê

O shadow DOM não muda a regra: a div dentro dele não é botão, não recebe foco e não tem estado.

O que corrigir

Dentro do shadow, use um button com aria-expanded e aria-controls (ids dentro do mesmo shadow root).

O que o navegador entrega ao leitor de tela (medido)

- text: Prazo de entrega

O que o axe acha (medido)

O axe não achou nada neste exemplo. É um problema que só aparece olhando a árvore de acessibilidade ou ouvindo com o leitor de tela.

Comportamento com o teclado (sonda disclosure, medido)

NÃO cumpriu: o gatilho recebe o foco do teclado. Observado: nenhum elemento (corpo da pagina).
NÃO cumpriu: estado aberto/fechado exposto (aria-expanded no botao ou <summary> de <details>). Observado: aria-expanded=None.
NÃO cumpriu: Enter alterna o estado do botao e o conteudo controlado. Observado: expanded None->None; conteudo visivel None->None.
NÃO cumpriu: o foco continua no botao. Observado: nenhum elemento (corpo da pagina).
NÃO cumpriu: Space alterna o estado do botao e o conteudo controlado. Observado: expanded None->None; conteudo visivel None->None.
NÃO cumpriu: o foco continua no botao. Observado: nenhum elemento (corpo da pagina).

Código

Código copiado

<meu-acordeao-ruim></meu-acordeao-ruim><script>customElements.define('meu-acordeao-ruim',class extends HTMLElement{connectedCallback(){var r=this.attachShadow({mode:'open'});r.innerHTML='<div id="wc-ruim-gatilho" style="cursor:pointer">Prazo de entrega</div><p id="wc-ruim-painel" hidden>Cinco dias úteis.</p>';r.getElementById('wc-ruim-gatilho').addEventListener('click',function(){var p=r.getElementById('wc-ruim-painel');p.hidden=!p.hidden;});}});</script>

Exemplo bom: Elemento personalizado com button no shadow

Por quê

O botão dentro do shadow é exposto ao leitor de tela com seu estado, e aria-controls funciona porque os dois ids estão no mesmo shadow root.

O que corrigir

Nada a corrigir.

O que o navegador entrega ao leitor de tela (medido)

- button "Prazo de entrega"

O que o axe acha (medido)

O axe não achou nenhuma violação (nível AA).

Comportamento com o teclado (sonda disclosure, medido)

cumpriu: o gatilho recebe o foco do teclado. Observado: button 'Prazo de entrega'.
cumpriu: estado aberto/fechado exposto (aria-expanded no botao ou <summary> de <details>). Observado: aria-expanded=false.
cumpriu: Enter alterna o estado do botao e o conteudo controlado. Observado: expanded false->true; conteudo visivel False->True.
cumpriu: o foco continua no botao. Observado: button 'Prazo de entrega'.
cumpriu: expanded=true mostra o conteudo; false o oculta. Observado: expanded=true conteudo_visivel=True.
cumpriu: Space alterna o estado do botao e o conteudo controlado. Observado: expanded false->true; conteudo visivel False->True.
cumpriu: o foco continua no botao. Observado: button 'Prazo de entrega'.

Código

Código copiado

<meu-acordeao-bom></meu-acordeao-bom><script>customElements.define('meu-acordeao-bom',class extends HTMLElement{connectedCallback(){var r=this.attachShadow({mode:'open'});r.innerHTML='<style>button{min-height:44px;min-width:44px;padding:0.5rem 1rem;font:inherit}</style><button type="button" id="wc-bom-gatilho" aria-expanded="false" aria-controls="wc-bom-painel">Prazo de entrega</button><div id="wc-bom-painel" hidden><p>Cinco dias úteis.</p></div>';var b=r.getElementById('wc-bom-gatilho'),p=r.getElementById('wc-bom-painel');b.addEventListener('click',function(){var a=b.getAttribute('aria-expanded')!=='true';b.setAttribute('aria-expanded',String(a));p.hidden=!a;});}});</script>

Exemplo ruim: Caixa de seleção personalizada sem papel nem teclado

Receber novidades

Por quê

Parece uma caixa de seleção, mas para o leitor de tela é só um texto. Não tem papel de checkbox, não tem estado marcado, não recebe foco.

O que corrigir

Use ElementInternals: role checkbox, ariaChecked, tabindex 0 e a tecla Espaço (veja o exemplo web-component-element-internals do MCP), ou simplesmente um input type=checkbox.

O que o navegador entrega ao leitor de tela (medido)

- text: Receber novidades

O que o axe acha (medido)

O axe não achou nada neste exemplo. É um problema que só aparece olhando a árvore de acessibilidade ou ouvindo com o leitor de tela.

Código

Código copiado

<caixa-ruim>Receber novidades</caixa-ruim><script>customElements.define('caixa-ruim',class extends HTMLElement{connectedCallback(){var r=this.attachShadow({mode:'open'});r.innerHTML='<span class="marca" style="display:inline-block;width:1.25rem;height:1.25rem;border:2px solid currentColor;vertical-align:middle"></span> <slot></slot>';r.querySelector('.marca').addEventListener('click',function(e){e.target.textContent=e.target.textContent?'':'✓';});}});</script>

Exemplo bom: Caixa de seleção personalizada com ElementInternals

Receber novidades

Por quê

O elemento ganha o papel checkbox, o estado marcado, foco e a tecla Espaço, tudo no próprio host.

O que corrigir

Nada a corrigir. Se um input type=checkbox resolver, prefira ele.

O que o navegador entrega ao leitor de tela (medido)

- text: Receber novidades

# Elementos personalizados, como o Chromium calcula (o snapshot acima pode nao mostrar o papel que vem de ElementInternals):
- caixa-bom: checkbox "Receber novidades" [invalid=false] [checked=false]

O que o axe acha (medido)

O axe não achou nenhuma violação (nível AA).

Código

Código copiado

<caixa-bom>Receber novidades</caixa-bom><script>customElements.define('caixa-bom',class extends HTMLElement{static get formAssociated(){return true;}constructor(){super();this.i=this.attachInternals();this.i.role='checkbox';this.i.ariaChecked='false';this.attachShadow({mode:'open'}).innerHTML='<style>:host{display:inline-flex;align-items:center;gap:0.5rem;min-height:44px}</style><span style="display:inline-block;width:1.25rem;height:1.25rem;border:2px solid currentColor;vertical-align:middle"></span> <slot></slot>';}connectedCallback(){this.tabIndex=0;var t=this;function alterna(){var on=t.i.ariaChecked!=='true';t.i.ariaChecked=String(on);t.shadowRoot.querySelector('span').textContent=on?'✓':'';}this.addEventListener('click',alterna);this.addEventListener('keydown',function(e){if(e.key===' '){e.preventDefault();alterna();}});}});</script>
